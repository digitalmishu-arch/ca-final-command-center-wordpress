# Changelog

## 0.1.0 — 21 October 2026

Initial WordPress plugin foundation: six subject seeds, schema version 1, academic reference editor, explicit verification/publication workflow, signed-in chapter explorer, per-student progress, server-enforced permissions, official resource URL policy, non-destructive deactivation, automated WordPress/MariaDB tests and reproducible ZIP packaging. The earlier repository prototype shortcode remains supported; its incompatible tables and private notes are preserved separately pending a reviewed migration. GitHub Actions builds an artifact for iPad installation; it does not deploy or merge.
