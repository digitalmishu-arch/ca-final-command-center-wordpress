# v0.8 iPad installation and acceptance — staging only

1. Open the release's **GitHub Actions** run in Safari. Under Artifacts download **ca-final-command-center-0.8.0**. In Files unzip the outer Actions archive once. Keep the inner **ca-final-command-center.zip** intact; it contains the installable plugin folder.
2. Take a staging database/files backup. Sign into **demo.cadeepanshuagarwal.in/wp-admin**. Plugins → Add New → Upload Plugin → choose the inner ZIP → Install → **Replace current with uploaded**. Do not uninstall or reset. Do not use the main production site.
3. Reload the student portal (close/reopen an old tab if assets are cached). Existing publications, entitlements and student data should still be present. **No academic ZIP reimport or republishing is required.** Later imports retain Upload ZIP → Preview → Publish All.
4. Explorer: verify five filters and one smart search. Try Ind AS 105, Ind AS 115 and an actual question number. Browse a zero-question syllabus heading. Open a row; switch List/One-by-One without losing its identity.
5. Open Show Answer in both themes, portrait and landscape. Check an accounting table's labels, amounts and horizontal scroll. Verify the source badge still opens the matching owner Drive PDF and displays its source page honestly.
6. Use Start → Pause → Resume → Finish. Under More open notes, save a distinctive test note, reload and sign out/in. Check that it persists. Add Important/tag/bookmark; open My Practice and compare the existing timing history. Check Dashboard drill-down counts against their tables. Repeat with another student; private data must differ.
7. MCQ Practice: four filters, one question, Previous/Next/counter. Select an option then Check Answer. Start a short **practice** timed test; save responses, navigate, submit and inspect actual results. Keys must stay hidden until submission. The held examination Q7 stays private.
8. Study Planner: complete CA Final/Both Groups setup, select an explicit personal date or labelled month-end target, study days and hours. Add a custom chapter or available sourced template. Use Coverage measure to choose first study, Revision 1/2 or completed mock preparation. Record revisions, mocks with marks and an actual study log. Inspect charts. Create a revised attempt; confirm the older plan remains in the picker. Try Intermediate and Foundation separately; Foundation has no groups. Missing chapter templates are custom-plan empty states.
9. ICAI Resources: check Final six, Intermediate six and Foundation four subject columns. Only indexed exact PDFs open; missing cells say Not indexed/Not yet available. Official directory links are separate from PDF cells.
10. Check compact mobile navigation, Back to Top after scrolling, both themes and touch dropdown readability on your **physical iPad Safari**. These are owner acceptance checks; automated Linux WebKit is not a physical iPad test.

WhatsApp: CA Final Command Center → Settings → Advanced Academic Tools → **Student experience**. Configure your actual community/channel URL, message, visibility dates and dismissal option. The banner is hidden until a valid URL is supplied. Resource metadata is maintained under Advanced Academic Tools → Resources, in the course/attempt PDF matrix editor.

If Notes reports a temporary error, use its Retry control. It must not show raw HTML or erase an existing note. Administrators can inspect bounded event codes in Student experience settings; see [the diagnosis report](NOTES-ROOT-CAUSE.md). No credentials or private notes should be posted publicly.
