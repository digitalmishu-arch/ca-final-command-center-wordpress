# Version 0.4 architecture and limits

The plugin remains WordPress/PHP/MySQL with vanilla JavaScript/CSS. No Node, separate website, Supabase, PDF worker, payment SDK or new WordPress plugin is required on hosting. Python/PyMuPDF/openpyxl and browser tools run offline/on CI only.

`CAFCC_Facets` adds independent concept/source/attempt search through existing topic relationships and an indexed ancestor closure. A topic choice resolves its exact edition/subject/path; IBS permits additional subject contexts. Chapters without numbered units are valid. Available concepts require reviewed paths with eligible published occurrences. SQL handles pagination (20 student cards, 50 Studio records). Display counts use actual visible data. Leading-wildcard text/alias search is measured at 10,000 synthetic records, not claimed to be an unbounded full-text search engine.

`CAFCC_Studio` retains private source evidence, original AI suggestions, source hashes/sections, owner edits, separate stage fingerprints and reviewer/time/revision audit. Materialization preserves adopted WordPress IDs or allocates new IDs deliberately. Every occurrence remains distinct. There is no repeat/newness inference. Master changes invalidate affected approvals; permitted-content IDs/revisions bind the publication gate. Answers require an exact occurrence and question/subpart/source mapping. Student APIs return no research payload; question lists never include answer text. Deliberate Show Answer makes a separate authenticated request. Public permitted HTML is allowlisted by the retained rights engine; original/licensed saved content requires both that engine's revision approval and Studio approval. Private review text is not a public-content source.

`CAFCC_Review_XLSX` implements bounded macro-free OOXML export/import. Authentication + REST nonce + administrator capability + server-held export manifest + current record revision are enforced independently of spreadsheet protection. Preview executes real eligibility checks in a rolled-back transaction; Apply revalidates and is atomic. No upload is extracted into public media, no public download link is created. Formula/external-link/DTD/ZIP limits are enforced. Direct review stays available without Excel.

`CAFCC_Access` uses WordPress credentials/reset flows, hashed expiring one-use email tokens, pending approval, manual plans, UTC start/expiry, suspend/cancel/renew and audit. Email changes require reverification. All legacy/current student REST APIs and progress writes enforce entitlement. Notes/bookmarks/progress derive the current user; clients cannot nominate another student. Hosting must deliver WordPress email reliably; no real external delivery was tested here. Rate limiting is local transient/IP/email based, not a distributed abuse service.

`CAFCC_Portal` supplies real frontend routes/shortcodes and navigation without overwriting/publishing pages. My Dashboard shows the same real saved-activity summary; My Practice provides the same explorer with bookmark/status filters; a separate planner is not implemented. Trend Analysis/Study Planner are honest Coming Soon. `CAFCC_Resources` publishes only administrator-reviewed official ICAI links. Optional page preparation creates drafts.

Future commerce: entitlement rows support plan key, status, start and expiry independently of a commerce provider. No order/payment callback is enabled. A future WooCommerce/Indian gateway adapter must validate a settled order through the supported provider, enforce event idempotence/refund/cancellation/renewal and audit before calling a dedicated grant service. A client redirect, unverified webhook or successful-looking browser screen must never grant membership. This adapter and recurring billing are unfinished.

Research stays separate: ignored local PDFs, extracted text, SQLite jobs, workbooks and logs never enter the plugin. PR #8 wraps PR #4's corrected visual engine in resumable batches with rights/layout gates. Public CI uses authored synthetic fixtures. Manual connector inventory refresh is implemented; scheduled Drive synchronisation/private worker hosting/credentials are not provisioned.

Unfinished academic work: complete approved six-subject detailed trees and historical law mapping; owner resolution of 181 proposal exceptions and AFM numbering conflicts; authorised processing of the other 417 catalogue sources; real MTP/exam layout validation; answer verification and rights approval. The current semantic suggestions are conservative and provisional, not a fully trained academic classifier. Safari/iPad hardware, actual Hostinger capacity/SMTP, concurrent-user load and external independent security review remain owner staging checks.
