# CA Final Command Center

Custom WordPress plugin for CA Final practice question tracking.

## Current scope (v0.1.0)
- Six CA Final subjects.
- Administrator-only manual academic question entry.
- Student dashboard embedded with `[cafcc_dashboard]`.
- User-specific practice statuses and private revision notes.

## Development
The installable plugin directory is `ca-final-command-center/`.

**Staging first:** Follow [Phase 1 staging guide](docs/PHASE1_STAGING.md). The code has not yet been validated in a WordPress staging runtime.

## Planned
Academic imports and tagging, repetition analysis, planner, chapter-wise analytics and paid access.
