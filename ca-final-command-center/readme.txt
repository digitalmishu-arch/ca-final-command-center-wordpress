CA Final academic references, rights-reviewed practice text, and private student progress, notes and bookmarks.

== Installation ==
Upload ca-final-command-center.zip via WordPress Admin > Plugins > Add New Plugin > Upload Plugin. Activate on a private staging site first. Use the CA Final Command Center admin menu. Add [ca_final_command_center] to a page accessible inside protected staging. No page is automatically created or published. See the repository README for iPad installation, caching and testing instructions.

== Data ==
Seeds six subjects and the sourced draft hierarchy retained from Version 0.2. No real question/answer prose or exam attempts are seeded. Full text requires an administrator's separate authorship/licence review. Unlicensed ICAI sources remain reference/link-only. No private research files are imported. Deactivation and plugin-file deletion preserve all records.
