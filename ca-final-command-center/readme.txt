CA Final academic references with administrator-only master records and private per-student practice progress.

== Installation ==
Upload ca-final-command-center.zip via WordPress Admin > Plugins > Add New Plugin > Upload Plugin. Activate on a private staging site first. Use the CA Final Command Center admin menu. Add [ca_final_command_center] to a page accessible inside protected staging. No page is automatically created or published. See the repository README for iPad installation, caching and testing instructions.

== Data ==
Seeds only six CA Final subjects. No real questions, chapters or exam attempts are included. Records must be reviewed by an administrator. Only verified published references from verified official sources appear to students. Deactivation and plugin-file deletion preserve database records.
